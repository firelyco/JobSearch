Daily processing: ready by 6 AM Eastern

The independent Vercel coordinator checks the pipeline every 10 minutes during the overnight window. Work starts at 1 AM Eastern. GitHub's 1 AM schedule is a backup; the independent coordinator can start a worker even if that schedule is delayed.

Connect the independent coordinator

  1. Create a fine-grained GitHub token for firelyco/JobSearch only. Grant Actions: Read and write, and Contents: Read-only.
  2. Add it as JOBSEARCH_GITHUB_TOKEN in Vercel Production environment variables. Do not paste it into chat or commit it.
  3. Redeploy the existing history service so the new variable takes effect. Cron authentication is configured separately through CRON_SECRET.
  4. Check daily pipeline status. Missing credentials or an overdue monitor are shown explicitly.

What completion means

A daily batch contains its discovered jobs and newly imported email links. Membership is retained across retries. Every eligible job needs a validated saved verdict; exhausted attempts, missing postings, unverified employer links, and incomplete source checks remain visible. The coordinator checks that the same batch is published on the live dashboard before calling it complete.

Paid assessment limits and completed-result reuse remain enforced. A blocked batch is not reset or repeatedly charged to make the status green. A batch first verified after 6 AM is marked completed late; remaining work at 6 AM is marked missed deadline.

Validation before relying on the deadline

  • Missing GitHub schedule and duplicate independent triggers.
  • Worker interruption, model interruption, and preserved retry limits.
  • Publication failure and stale dashboard files.
  • Daylight-saving changes, late completion, and overdue monitor heartbeat.
  • Authenticated live dry run with no worker dispatch or AI calls, followed by an observed overnight run.

No service can promise zero outages. The completion state and deadline result must remain explicit when a dependency fails.
